This is folder for IEEE 39-bus system.

It consists of several files:
  a. xlsx file, containing bus, external grid, generator, transformer, lines, and loads data.
  b. jupyter notebook file, containing source code to create IEEE 39-bus system from the xlsx file and run load flow of the IEEE 39-bus system. 
     this notebook will also give output to a .p file, which can be called in another notebook file
