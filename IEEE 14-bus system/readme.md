This folder contains source code for IEEE 14-bus system

In this folder, you can find several files as follow.
  a. xlsx file which contains data of bus, external grid, generator, transformer, lines, loads, and shunt capacitor which will be used to construct the IEEE 14-bus system
  b. ieee14bus.ipynb file which contains source code to create the IEEE 14-bus system network, run the load flow, and create .p file which can be used to call this network in another
  ipnyb files
  c. DC_OPF_ieee14bus.ipynb file which contains source code to conduct OPF for the IEEE 14-bus system.
